## Preflight and interfaces

| Boundary | Decision |
|---|---|
| Decimal → Money | Reuse the unchanged Decimal API and numeric limits. Money construction never rounds. |
| Money → eval | Root integrates MoneyValue, strict arithmetic and builtins, preserving v0.1 behavior. |
| eval → contracts | Contract decoder returns positional eval.Value arguments; a single Evaluator runs the file and calls the entry under one budget. |
| eval → trace | Events use evaluated inputs/results and source spans; nil sink incurs no formatting work. |
| contract → CLI | JSON mode requires -file, -contract and -input; stdout has exactly one result/error record. |
| trace → CLI | Write requested trace before JSON success; failure is E_TRACE_IO/exit 2. |
| trace limit | Explicit truncation, no numeric result changes; deep-copy retained events. |
| GitHub | finlang, private; confirm selected connected account and actual remote before push. |

## Clarifications

- Modes remain explicit. Money does not infer legal currency precision.
- Contract errors have no source position; arithmetic/runtime errors preserve their inner source span.
- Trace schema is JSONL: header, event rows, summary with explicit trace_truncated.
- Plain -trace requires a source file; it is not a multi-line REPL recording feature.
- A requested trace path cannot be the source, contract or input path, to avoid overwriting a run's inputs.
- COBOL execution and production financial-system compatibility remain v0.3.
