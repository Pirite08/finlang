# v0.1 설계 선택과 확인 결과

2026-10-31.

| 문제 | 선택 | 확인한 결과 |
|---|---|---|
| 이진 부동소수점의 십진 표현 | 원문에서 정수 계수·스케일 생성 | 0.1+0.2=0.3, 별도 유리수 기준과 비교 |
| 큰 수와 구현 범위 | big.Int, 계수 128자리·스케일 36 | 정상 결과와 의도한 한도 거부를 함께 확인 |
| 공유 계수 변경 | 비공개 계수와 연산 전 복사 | 피연산자를 재사용해도 값이 유지됨 |
| 반올림 방향 | 자리·모드를 호출에 명시 | 양수·음수·절반·자리 올림을 독립 기준과 비교 |
| 표시와 값 | 정규형과 FormatAt 분리 | 10과 10.00을 구분하고 숨은 반올림 거부 |
| 입력 복잡도 | 소스·토큰·AST·평가·호출 한도 | 깊은 구문과 긴 연산 체인, 재귀가 진단으로 종료 |
| 오류 뒤 계속 실행 | 언어 오류는 복구, 출력 I/O는 중단 | 검토에서 발견한 실패를 회귀 테스트로 수정 |

초기 표현 실험은 런타임 float64, 문자열에서 읽은 유리수, 준비한 공통 스케일 정수 계수를 사용했다. 파싱 포함 여부가 서로 달라 공정한 속도 비교로 해석하지 않았다. 직접 문자열 자릿수 산술 구현과 전체 비교 연구는 후속 실험이다. 실제 Decimal 엔진의 정확성은 별도 기준으로 검증했다.
