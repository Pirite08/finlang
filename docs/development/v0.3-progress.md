## Execution decisions

- Work in the existing clean checkout on codex/v0.3; no extra worktree is needed. Baseline go test ./... passed before changes.
- Use the existing three contracts and DSL rules without widening fields or changing rounding policies.
- COBOL protocol: first stdin line is case count; each following line is id|arg1|arg2|arg3 (unused arguments omitted). Only contract-accepted decimal strings enter COBOL. Output per case: id|ok|amount|branch or id|error|E_LEGACY_RANGE|branch. Branch is none for interest/sum, low/high for fee. Integer outputs have no decimal suffix; USD output always has two decimal places and zero has no minus sign.
- Compile each reference once using cobc -x -free -std=cobol2014 -freserved=NEAREST-EVEN. Use direct os/exec arguments and bounded execution. Fixed seed, at least 1,000 accepted inputs per rule, manual anchors, strict comparator tests and separate rejected-input counts.
- Evidence JSONL contains compiler/Go/platform metadata, exact commands, source and contract hashes, each input and both outcomes, then summary. A missing compiler is an explicit skip unless FINLANG_REQUIRE_COBOL=1, which fails release verification.
- Independent work lanes: COBOL source fixtures; compatibility harness/generators; performance/fuzz/usability materials. Root owns toolchain, integration, version, documentation and publication. No overlapping file ownership.
- Environment adaptation: the host is Windows and has native GCC/MSYS2; use an official native GnuCOBOL toolchain if available rather than installing WSL or changing the field profile. Record the actual compiler and environment; do not claim Linux execution.
- Human usability measurements require real participants. Prepare reproducible tasks and recording sheets, but leave measurements explicitly unrun. Do not fabricate participants or claim the original human-evaluation gate passed. This turn's requested deliverable is the three-rule comparison and boundary verification.
